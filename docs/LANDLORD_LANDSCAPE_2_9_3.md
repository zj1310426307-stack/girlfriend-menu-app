# 2.9.3 斗地主横屏牌桌

## 目标

斗地主进入后使用独立横屏页面，采用国内移动端斗地主常见的信息层级：左右对手、中央出牌区、底部本人手牌和就近操作按钮。界面只借鉴成熟产品的交互规律，不复制 JJ 斗地主的商标、人物、贴图、音效或其他美术资源。

参考：

- [JJ 斗地主公开游戏画面（小米游戏中心）](https://game.xiaomi.com/viewpoint/1543958016_1745481945962_149)
- [Taro 页面配置 `pageOrientation`](https://docs.taro.zone/docs/page-config)

## 实现

- 页面配置固定 `pageOrientation: landscape`、`navigationStyle: custom`、`disableScroll: true`。
- 同时使用 `PageMeta` 声明横屏，兼容分享进入和页面重进。
- 大厅改为左右双栏，横屏内可完成称呼、模式、AI 难度、建房和加房。
- 对局使用深绿色牌桌与暖金色状态强调；左右显示两位对手，中间显示当前牌型，底部显示操作和本人手牌。
- 手牌使用负间距叠放，选中牌向上抬起；提示按钮直接使用服务端返回的合法牌组。
- 小高度横屏使用紧凑媒体查询，保留安全区并避免系统胶囊区域遮挡。
- 服务端洗牌、发牌、叫地主、合法牌型、提示、AI 和胜负判断不变。

## 验证

```bash
cd miniprogram
npm run build:weapp
npm run test:landlord
```

`test:landlord` 校验最终编译配置和牌桌关键结构。微信开发者工具自动化接口不会始终自动旋转模拟器，因此真机/模拟器视觉验收时仍需确认设备已允许自动旋转；开发者工具可手动点击旋转按钮检查横屏布局。
