## V2.8 风险盘点

| 风险 | 当前事实 | V2.8 处理 |
| --- | --- | --- |
| 客户身份 | 仍信任可伪造的 `X-Customer-Id` | 新建设备会话、Bearer token 哈希存储和旧标识一次性认领 |
| 订单越权 | 历史接口可按任意 customer_id 查询，详情/评价缺少完整归属校验 | 改为 `/orders/me`，详情、评价和再次点单统一校验归属 |
| 管理令牌 | 当前令牌不是带过期时间的标准签名载荷 | 改为 12 小时 HMAC 签名令牌并统一校验 HTTP/WS |
| 图片 | 只有 Render 本地目录存储 | 抽象 local/S3-compatible，校验真实图片并去 EXIF |
| 实时房间 | 大话骰/五子棋核心态仍依赖进程内存 | 建立可替换状态仓储边界、会话令牌和明确失效提示；不伪称已完成多实例无缝恢复 |
| 随机公平 | 在线大话骰仍接收客户端骰值 | 改由服务端生成并广播结果 |
| 数据时间 | `desired_time` 是展示字符串，状态变更无审计流水 | 新增 UTC `desired_at`、`status_updated_at` 和状态事件表 |
| 数据保护 | 无可执行备份恢复脚本和演练记录 | 增加备份、校验脚本与 SQLite 演练；PostgreSQL 提供 `pg_dump/pg_restore` 流程 |
| 环境配置 | 小程序源码重复硬编码生产域名 | 统一 development/staging/production 配置并由 API Origin 派生 WS |
| 正式发布 | 尚无双真机全链路验收证据 | 版本保持 `2.8.0-rc.1`，不标记最终稳定版 |
